# Reporting security issues

Do not post credentials, private location data or exploitable live-instance details publicly. Contact the affected instance operator or use the repository's private vulnerability reporting feature once a remote repository is configured. No staffed security response address or guaranteed response time is currently advertised.

This is a pre-release development build, not a completed security audit. See docs/SECURITY.md, docs/PRIVACY.md and the validation report for current controls and limitations. Only the current development version is maintained; no stable support policy has been activated.
