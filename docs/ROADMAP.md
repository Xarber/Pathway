# Remaining roadmap

The first slice is intentionally integrated: users can coordinate using accounts, accepted invitations, independent consent, foreground location, statuses, chat and revocation. The full specification is still substantially larger.

## Release-critical next work

1. Execute PostGIS/Compose and signed native build validation; test physical iOS/Android location and revocation.
2. Complete email verification/recovery, abuse controls, WS Origin/backpressure/connection limits and session lifecycle hardening.
3. Integrate notifications with permissions, per-event preferences and privacy-safe delivery; background sharing with supported iOS/Android services, explicit consent and stop actions.
4. Complete automatic update discovery/channel metadata, secure direct-APK installer, managed-store updates, What's New integration and artifact/release validation.
5. Test accessibility, Dynamic Type, responsive rotations, permissions, interruption/reconnection and actual battery use.

## Group coordination

Schedule/deadline planning, delegated organizers/guests, safe public-place candidate discovery, automatic meet-along-route proposals, shared route segments/group confirmation, explicit transit/GTFS support, route recalculation and richer per-user transport preferences. Current meeting comparison is limited to consented fresh precise locations and user-proposed candidates.

## Privacy and architecture

Privacy zones/private destinations, configurable metadata retention/export, end-to-end encryption feasibility, P2P transports for trusted local coordination, encrypted local sensitive metadata, numbered migration upgrades, multi-replica event ordering and stronger audit/minimization. Do not expand infrastructure without a concrete tested need.

## UADS completion

Full Ideas history/batch/Markdown/sync and changelog references, extension registry/permissions, native Liquid Glass surfaces and layered Apple icon workflows, Live Activities/widgets/watch companions, release branding/screenshots/banners, authorized alternative distribution metadata. No advanced integration is represented as implemented merely because it appears here.
