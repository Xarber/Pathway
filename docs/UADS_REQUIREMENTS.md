# Pathway UADS requirements

The supplied Sections 1–52 form the `sections-1-52` baseline. [The registry](../config/uads-requirements.json) groups related obligations by stable ID and source section. [The manifest](../uads.json) records applicability and evidence separately from feature inventory. The registry is an initial traceability map. Individual obligations within each group still require verification.

Run `npm run uads:validate` for schema, applicability, exception expiry and evidence path checks. The validator does not establish functional compliance. Use the workflow result, native artifact receipts, browser results and deployment evidence for functional claims. No exceptions are approved.
