# Contributing

Read AGENTS.md and docs/INDEX.md. Develop on testing or an isolated feature branch; use Conventional Commits, focused changes and accurate documentation. Preserve user data and existing behavior. Never include tokens, private Ideas, precise user locations, keystores or production database dumps.

Run typecheck/tests and affected exports after an implementation batch. Record the platforms actually tested. Never equate browser success with native verification. Keep provider fixtures explicitly simulated and respect map/data licenses. Pull requests must describe behavior, validation and remaining risks. No public contribution destination is currently configured.

All original contributions use AGPL-3.0-only. Do not copy incompatible code/assets or change the license without authorization.
